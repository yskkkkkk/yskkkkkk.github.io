A personal developer blog and portfolio site built with [Astro](https://astro.build).

## Features

- **Content Collections** — type-safe blog posts and project entries with Zod schema validation
- **Sitemap** — auto-generated `sitemap.xml` via `@astrojs/sitemap`
- **GitHub Actions** — automated build and deploy to GitHub Pages on every push to `main`
- **TypeScript** — full type safety across components and content
- **Zero JS by default** — static HTML output, fast load times

## Stack

| Tool | Role |
|------|------|
| Astro 4 | Static site generator |
| TypeScript | Type safety |
| GitHub Actions | CI/CD |
| GitHub Pages | Hosting |
