요즘 토이 프로젝트를 진행하며 neon, OCI, Vercel, Google Search Console.... 셀 수 없이 많은 메일들이 와서 정리하다가 카카오 디벨로퍼스에서도 메일이 왔길래 흥미롭게 눌렀습니다.

7월 21일부터 카카오 맵 API 정책이 바뀐다는 내용이었습니다.

---

카카오 API는 꽤 오래 쓰고 있습니다. SSAFY 프로젝트 때 처음 OAuth2.0을 연동한 게 시작이었는데, 이후 `pet-pass`를 만들면서는 지도 API도 붙여봤습니다. 이번에 `pick-a-meme`에서 다시 OAuth2.0이 필요해져 오랜만에 콘솔을 열었거든요.

---

이번 변경의 핵심은 두 가지입니다.

신규 API 네 가지가 추가됩니다. 대중교통 경로, 도보 경로, 자전거 경로 탐색과 정적 지도 API입니다. 각각 하루 **1,000건** 무료에, 초과 시 대중교통·도보·자전거는 요청당 **10원**, 정적 지도는 **2원**입니다.

그리고 무료 할당량 기준이 앱 단위에서 계정 단위로 바뀝니다. 개발자 계정 기준으로 첫 번째로 활성화한 앱에만 무료 할당량이 적용되고, 두 번째 앱부터는 Biz Wallet을 연결하고 유료 API 설정을 마쳐야 사용할 수 있습니다.

7월 21일 이전에 이미 활성화된 앱들은 기존 무료 할당량이 그대로 유지됩니다.

---

기존 앱에 영향이 없다니 다행이긴 합니다.

그런데 "첫 번째 앱만 무료"라는 기준이 생기면, 사이드 프로젝트를 여러 개 굴리는 입장에서는 좀 피하기 어려운 상황이 생길 수도 있겠다는 생각이 들었거든요. `pet-pass`에서 이미 지도 API를 쓰고 있는데, 나중에 다른 프로젝트에서 지도가 필요해지면 그때부터는 바로 유료 구간인 거니까요.

신규 API가 추가된 건 솔직히 반갑습니다. 경로 탐색류는 직접 구현하기 꽤 번거롭거든요. 다만 전체적인 방향이 점점 유료화 쪽으로 가는 게 느껴져서, 마냥 반가운 공지는 아니었습니다.

---

제 생각에는 토이 프로젝트 단계에서는 지인, 친지들의 아이디를 이용해서 첫 번째 무료 티어를 낭낭하게 뽑아먹지 않을까요? 의문의 개발자 카카오 계정이 늘어날 예정일 듯합니다.
